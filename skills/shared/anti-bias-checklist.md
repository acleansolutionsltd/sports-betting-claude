# Anti-Bias Checklist

> Run every candidate bet through this list before finalizing. A single red flag doesn't mean "no bet" — it means "rerun the analysis cold and make sure the edge is real, not emotional."

---

## The checklist

For every bet Claude recommends, verify:

### Recency bias
```
□ Am I overweighting last week's performance?
  Red flag: "They looked great last Thursday" without supporting data
  Test: Does the edge still exist if I ignore the last 2 games?
```

### Narrative trap
```
□ Is there a compelling story I'm fitting data around?
  Red flag: "They're due for a win" / "They always show up in big spots"
  Test: Strip the narrative — what do the numbers say without the story?
```

### Public contrarian trap
```
□ Am I fading the public just to be contrarian?
  Red flag: Fading a team only because 70% public is on them, no model backing
  Test: Do I have a calculated edge independent of the public % signal?
```

### Recency market bias
```
□ Has the market already priced in the thing I think is my edge?
  Red flag: Thinking you know about an injury "before the market" when the line already moved
  Test: Check the line movement — if it's already moved 1+ points, the market knows
```

### Confirmation bias
```
□ Am I only looking at data that supports the bet I already want to make?
  Red flag: Found three supporting stats and ignored two contradicting ones
  Test: Actively search for the case AGAINST the bet — does the edge survive?
```

### Tilt detection
```
□ Am I betting this game because I lost earlier today and need to recover?
  Red flag: Increasing unit size after a losing streak
  Red flag: Betting a sport or market I don't normally bet "for action"
  Test: Would I have identified this bet if I'd had a winning day?
```

### Emotional attachment
```
□ Do I have a rooting interest in this game?
  Red flag: Betting your favorite team because "you believe in them"
  Red flag: Betting against a team you hate because you want them to lose
  Rule: Never bet games where you have a rooting interest unless the edge is Tier A
```

### Name/brand bias
```
□ Am I overweighting a famous player or program?
  Red flag: "LeBron won't let his team lose" / "Alabama always covers"
  Test: Replace the team names with anonymous Team A and Team B — would you still bet it?
```

### Recency line movement confusion
```
□ Am I chasing a line that already moved in the direction I wanted?
  Red flag: Bet was +3 when I found it; now it's -1 and I'm still taking it
  Rule: If the line moved more than 1 point against you before you bet, recalculate EV
```

### Sample size delusion
```
□ Am I citing trends with too-small sample sizes?
  Red flag: "They're 5-0 ATS in night games" (5 games means nothing)
  Red flag: "This pitcher is 8-1 in day games" (ERA splits need 200+ IP to matter)
  Rule: Minimum 20 data points for any trend to be considered meaningful; 50+ preferred
```

---

## How to handle red flags

```
0 red flags → proceed with calculated confidence tier
1 red flag → reduce confidence tier by one level (Tier A → B, Tier B → C)
2 red flags → reduce to Tier C (1 unit max) or pass
3+ red flags → pass, regardless of calculated EV
```

---

## The 10-second gut check

Before every bet, ask:

> *"If I had to explain this bet to a skeptical professional bettor, would my reasoning survive 5 minutes of questioning?"*

If the answer is "probably not" — pass.

---

## Post-bet check (before confirmation)

After deciding to bet but before placing:

```
□ Did I get the best available line? (check 2+ books minimum)
□ Is the game/market I calculated still the same? (lines shift)
□ Is there any breaking news in the last 2 hours I might have missed?
□ Does my unit size follow the bankroll rules?
□ Have I hit my daily unit cap?
```
